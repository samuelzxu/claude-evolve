---
name: evolve-status
description: Check the progress of an active evolution run
---

Show the current state of an evolution run including generation count, best score, bandit statistics, and island status.

## Usage

```
/evolve-status
```

## Output

- Current generation / total generations
- Best combined score and which program achieved it
- Bandit arm selection counts and mean rewards
- Island population sizes and migration events
- Recent generation log entries
